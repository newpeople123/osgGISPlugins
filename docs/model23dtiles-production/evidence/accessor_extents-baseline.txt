0. 为什么三条判据都要留着（此前只口头说过"min/max 全等"）
---------------------------------------------------------
三条互相拦不住，每条都做了阳性对照：

- 对照 A（荒谬顶点）：`matrix_a34/t02_thin_features` 就是 A-38 唯一那次现场。
  扫描报 **b3dm >1e6 = 3 个瓦片**（t0/t4/t6），与 `evidence/a38-forensics.txt`
  记录的三个文件**逐一对上**；同一批的 `声明≠实算 = 0`——因为那次污染的顶点
  连 accessor 的 `max` 一起被写了（`pos data max=[6.555e+10,-1.195e-8,4.474e+27]
  declared max=[65549959168,-1.1951946987664996e-8,4.474249806084812e+27]`）。
  结论：**min/max 全等拦不住 A-38**，必须有幅度判据。
- 对照 B（包围体脱钩）：把 `matrix_a34/t01_plane_curved/tiles/t0.b3dm` 里
  POSITION 第 1 个顶点的 x 改写成 `1234.5`（声明 max[0]=50，远低于 1e6）后扫描：
  **声明≠实算 = 1（t0.b3dm acc1）、非有限 = 0、b3dm >1e6 = 0**。
  结论：幅度判据拦不住"包围体与几何脱钩"。
- 对照 C（非有限分量）：同一份 t0.b3dm 把第 2 个顶点的 x 写成 `NaN` 后扫描：
  **非有限 = 1、声明≠实算 = 0、>1e6 = 0**。
  NaN 参与 `<`/`>` 比较恒为 false，所以它既不动实算 min/max 也不动幅度——
  **这一条必须单独查**，另两条都是结构性漏检。
